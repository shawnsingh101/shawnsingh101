## Scenarios
- A login form's log shows the username `admin' --`: an attempt at {{SQL injection|which attack?}}.
- A comment on a forum contains `<script>` and visitors' sessions are stolen: stored {{cross-site scripting (XSS)|which attack?}}.
- The finance clerk gets a call "from the CEO", urgent, asking for gift cards: {{vishing|what?}} using authority and urgency.
- Hundreds of accounts each see one failed login with "Winter2026!": password {{spraying|what?}}.
- A web server log shows a request for `/download?file=../../etc/passwd`: directory {{traversal|what?}}.
- Logins from many countries succeed using emails and passwords from another site's leak: credential {{stuffing|what?}}.
