## Scenarios
- A kiosk PC should only ever run the check-in app: use an application {{allow list|what?}}.
- New ransomware has no known signature, but the tool flagged a program encrypting hundreds of files a minute: that's {{EDR (endpoint detection and response)|what?}}.
- A salesperson's laptop was stolen from a car, but the data is safe: full-disk {{encryption|what?}}.
- A scan finds Telnet running on a server nobody uses it on: {{disable|do what to?}} the service.
- A lost company phone can be erased from the office: remote {{wipe|what?}}, through MDM.
