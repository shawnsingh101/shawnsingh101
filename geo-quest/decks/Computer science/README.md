# Computer science

Same pattern as Science: a folder per area, a deck per textbook chapter (numbers set the order).

- **Information systems**: OpenStax *Foundations of Information Systems* (CC BY 4.0), 12 chapters, one card each so far:
  1 Fundamentals of Information Systems · 2 Data Management and Information Systems Business Strategies · 3 Database
  Management Systems · 4 Systems Analysis, Design, and Development · 5 Information Systems Security Risk Management ·
  6 Enterprise Security, Data Privacy, and Risk Management · 7 Cloud Computing and Managing the Cloud Infrastructure ·
  8 Data Analytics and Modeling · 9 Information Systems Project Management · 10 Emerging Technologies and Frontiers of
  Information Systems · 11 Global Information Systems · 12 Ethics, Sustainability, and Social Issues in Information Systems
- **Python**: OpenStax *Introduction to Python Programming* (CC BY 4.0), one deck per chapter plus a harder deck beside
  it (`depth: deep`). Done: 1 Statements · 2 Expressions · 3 Objects. Next: 4 Decisions · 5 Loops · 6 Functions ·
  7 Modules · 8 Strings · 9 Lists · 10 Dictionaries · 11 Classes · 12 Recursion · 13 Inheritance · 14 Files ·
  15 Data science. Every "this prints" answer is checked by running it.
- **Under the hood**: how this app is built, from its own files. Done: 1 The repo · 2 Git and GitHub. Next: 3 Data
  (Wikidata, the sync) · 4 The basics in real code (variables, lists, loops, functions, with Python beside the
  TypeScript) · 5 Structures (the tree of life, the time scale) · 6 The app (screens, saved progress) · 7 Algorithms
  (spaced repetition, search) · 8 Testing. Cards quoting code name their file (`source:`); the audit checks it's still true.
- Planned: algorithms and data structures (OpenStax *Introduction to Computer Science*); practice mode for writing Python.

To add cards: name a chapter ("5 more cards from Python chapter 4"); they're written from that chapter's text on
openstax.org, in our own words.
